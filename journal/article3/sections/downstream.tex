\subsection{Preliminary downstream signal: LLM test generation}
\label{sec:downstream-prelim}

The structural extension reported in Section~\ref{sec:empirical} is a
prerequisite for downstream impact, not a demonstration of it. As a
preliminary downstream probe we compare two configurations of an
LLM-based test generator: \emph{P3} (the isolated baseline spec is
attached to the class under test as JML) and \emph{P3C} (the
compositionally-refined spec is attached instead). Both feed the
class source plus the spec into \texttt{gemini-2.5-flash} with
temperature $0.3$, $5$ generation runs per class. The 11-class
subset is the same Commons Lang 3 fa\c{c}ade used in the
predecessor LLM study~\cite{edmonds2026inference}.

Table~\ref{tab:downstream} reports the mean number of test methods
the LLM emits per run, for each class. Three classes
(\texttt{NumberUtils}, \texttt{MutableDouble}, \texttt{Range})
produced no extractable code in either phase (the model's response
exceeded our 16{,}384-token output budget before the closing markdown
fence, and the extractor reports zero tests in that case); these
rows are honest zeros, not failures of the comparison.

\midrule

\textbf{Interpretation.} This is a \emph{preliminary} signal only. The
refined context yields more test methods on six of eight classes
(largest gains on validation-heavy code, where branch-conditional
clauses add case structure), with one substantial regression
(\texttt{CharUtils}, $-23\%$, where disjunctive obligations appear to
be read as a single assertion). Per-class variance is high and
$n{=}11$ precludes a significance test. Crucially we report extracted
test \emph{count}, not mutation-killing rate: the generated tests did
not compile cleanly in our environment (un-stripped markdown fences;
surrogate-pair \texttt{char} literals from Gemini-2.5), so the
mutation-coverage comparison --- the measurement that would actually
establish downstream value --- is deferred, with the generated tests
committed to the replication package for independent
PIT~\cite{coles2016pitest} analysis. This subsection establishes only
that the P3 vs P3C delta is non-zero; it is not itself evidence of
downstream improvement.
