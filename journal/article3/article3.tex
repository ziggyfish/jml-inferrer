\begin{abstract}
Heuristic specification inferrers compute a per-method specification
from local syntactic evidence. When a method calls another, the
callee's specification is typically incorporated by single-pass
propagation: at each call site, the callee's preconditions
(substituted for actual arguments) are appended to the caller's
precondition set. A natural question is whether this single pass is
\emph{compositional} in the sense that matters --- whether a second,
top-down weakest-precondition (WP) refinement pass would discover
additional preconditions that the isolated pass missed. We implement
the second pass for an existing JML inferrer (a 414-line analyser
that walks each method's body in reverse-topological order, lifts
callee specifications through enclosing branch guards, emits
disjunctive obligations over polymorphic-dispatch candidates, and
iterates to a fixpoint on cyclic strongly-connected components) and
measure its effect on five open-source Java libraries spanning four
idiom families (Apache Commons Lang, Commons IO, Commons Math, jOOL,
Vavr): 1{,}712 source files and 21{,}052 inferred methods in total.
The result is unambiguous: \textbf{the second pass refines 23--43\% of
methods in each library's cache (median 35.53\%) and adds 45{,}740
new precondition clauses overall.} Branch-conditional implications
of the form \texttt{guard ==> obligation} dominate on four libraries
of five (46--67\% of new clauses), and disjunctive obligations from
polymorphic dispatch are present on every library (1.8--9.8\%); both
are shapes the single-pass propagation cannot produce because it
lacks the control-flow context the WP walk supplies and resolves
each call to a single nominal callee. The single pass does
\emph{not} subsume the compositional pass on any library studied.
A version-step instance --- inferring across Commons Lang 3.12.0 and
3.14.0 --- surfaces 525 candidate behavioural changes and 144
strengthened preconditions, the candidate-breaking artefact a
specification-level compatibility checker would consume.
\end{abstract}
