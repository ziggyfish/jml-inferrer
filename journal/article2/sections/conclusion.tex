\section{Conclusion}
\label{sec:conclusion}

Automatically inferred JML specifications can be embedded in compiled Java artefacts and REST API descriptions without loss: a runtime-retained annotation \texttt{@JmlSpecs} written by an ASM-based embedder, plus a parallel OpenAPI~3.x extension family (\texttt{x-jml-*}). Roundtrip is lossless on six libraries totalling 39{,}268 methods (synthetic) and on 22{,}881 real-inferred specs across the same six libraries' source trees; overhead is 4.63--10.20\% on real inferred specs after the format-optimisation step (Section~\ref{subsec:format-opt}, a 31\% reduction over the v1 per-clause format on the measured corpus); the OpenAPI extension is preserved unchanged by \texttt{swagger-parser}~2.1.x; and embedded classes load correctly in JVMs without the annotation type. With the inference engine of~\cite{edmonds2026inference}, the path from source code to consumer-accessible contract is complete. Follow-up threads include validation on the four remaining protocol libraries (jsoup, JFreeChart, JUnit, AssertJ), integration with the LLM-based test generator of~\cite{edmonds2026inference}, and extending inference to compose specifications across method boundaries --- with this carrier transporting the composition.
